# А*-Предобработчик


Веб-приложение для визуализации, сравнения, редактирования и подготовки исторических данных скважин для дальнейшего использования в гидродинамическом симуляторе "А*". Загружает данные из Excel/CSV, выгруженных из корпоративных БД, классифицирует параметры, строит интерактивные графики, позволяет редактировать значения и сохранять результат в шаблон загрузки в "А*". Работает локально в браузере пользователя – без доступа к сети.

## Ключевые особенности

- **Полная синхронизация интерфейса.** Таблица параметров, графики, карточки скважин и карта работают как единое целое: выбор скважины, зум и фильтры мгновенно отражаются во всех модулях.
- **Серверная обработка данных.** Все загрузки, преобразования и классификация выполняются на бэкенде на Python – фронтенд остаётся лёгким и отзывчивым.
- **Работа без интернета.** Все библиотеки и зависимости хранятся локально: приложение разворачивается в браузере пользователя и не требует сетевого доступа.
- **Загрузка из разных источников.** Поддержка Excel/CSV из нескольких корпоративных БД (NGT, ШТР, КЛАД) плюс распознавание пользовательских файлов и создание собственных источников.
- **Интерактивный редактор выбросов.** Shift + перетаскивание точки — правка значения; Ctrl + выделение области – операция над интервалом; Ctrl + клик по параметру – режим сшивания.
- **Сшивание параметров.** Объединение двух параметров в один пользовательский с автоматическим сохранением и повторным использованием.
- **Сплит-режим.** Одновременный просмотр двух скважин с синхронизацией зума и тултипов.
- **Фильтры параметров.** Базовый фильтр с автовыбором лучших суточных параметров, три дополнительных пресета, «все давления», «вся обводненность» и фильтр по типу скважин (добывающие / нагнетательные).
- **Пересчёт дебита жидкости.** Расчёт дебита жидкости по характеристикам работы ЭЦН с индивидуальными настройками (базовая частота вращения и номинал) для каждой скважины.
- **Блокировка скважин.** Кнопка Lock исключает выбранную скважину из действия фильтров.
- **Аннотации на графиках.** Текстовые параметры отображаются как вертикальные линии прямо на графиках.
- **Карта скважин.** Зум, панорамирование и выбор скважин по координатам.
- **Экспорт в Excel.** Выгрузка выбранных скважин и параметров в формате, готовом к загрузке в «А*».
- **Шаблоны классификации.** Сохранение и загрузка пользовательских настроек классификации параметров.
